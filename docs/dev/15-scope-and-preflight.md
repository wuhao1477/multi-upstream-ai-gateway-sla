## 1. 一期 / 二期范围划分（已确认）

> ⚠️ **真相源**：分期结论已写入 [PRD §2.1](../PRD.md)（需求文档的正式范围节）。本篇是该决策的**展开说明与依据**；若两者冲突，**以 PRD §2.1 为准**。

### 1.1 一期聚焦：SLA 自研网关

**目标**：把"最简单的智能调控 + SLA 保障"做扎实、做正确。

| 域 | 一期包含 |
| --- | --- |
| 上游对接 | 自研直连、Responses/CC 字节透传、SSE 旁路观察（[03](./03-upstream-layer.md)） |
| SLA 核心 | 内容感知 TTFT、动态期限、**首字前接管**、取消传播止损 |
| 智能调控（基础） | 按健康度/余额/容量/价格/故障域筛选与排序候选，生成 RoutePlan |
| 账本 | 逐 Attempt 账本（单一真相源）、价格版本、成本计算 |
| 采集 | **价格 + 余额 + Key 额度**采集（三家族适配器，[04](./04-collector-adapter.md)） |
| 平台底座 | 多实例、协议、数据边界、Key 存储、规模、管理 API |

### 2.1 范围类 —— 已定论

| # | 议题 | **决定** | 对设计的影响 |
| --- | --- | --- | --- |
| **S1** | 真实业务测活（FR-060~067）／受控验证（**FR-121，一期**） | ✅ **一期不做主动测活**（不为探测额外发请求），但**必须做受控验证 canary**——把本来就要发的铜级请求按硬上限分给待验证 binding。**理由**：只做被动统计 + 人工开启会形成死循环（`low_confidence` 不作主渠道 → 拿不到样本 → 永远 `low_confidence`），把渠道验证推迟到故障现场（对抗性审查第 7 轮 [high]） | FR-060~067 移入二期；[05 §2.0](./05-scheduling-and-operations.md) 定义 canary（`health_state='canary'` + 3 个硬上限 + 5 条准入），§2.1~2.3 测活预算体系一期不实现；AC-08 验证 canary 闭环；AC-09/10 推迟；`probe_kind` 字段保留 |
| **S2** | 缓存亲和调度（FR-054/055/056） | ✅ **做基础版**：连续会话优先沿用上一轮渠道（会话粘性）；**不做**切换损失预测与缓存率目标约束 | [05 §1.2](./05-scheduling-and-operations.md) 排序键含"会话粘性"；FR-056 切换抑制移入二期；缓存率 ≥90% 目标**一期不承诺** |
| **S3** | SLA 等级数量 | ✅ **一期只实现单级**，但**表结构与配置预留多级**（二期加等级不改结构） | [02 `sla_targets`/`routing_policies`](./02-data-model.md) 结构不变；[05](./05-scheduling-and-operations.md) 的分级排队/容量保留/优先序**一期简化为单套策略** |
| **S4** | 数据许可硬过滤（FR-093） | ✅ **建表 + 实现过滤层，开关默认 `false`** —— 载体已具体化为 [02 §2ter `data_policies`](./02-data-model.md)（四维 allow/deny）+ [09 `/admin/data-policies`](./09-admin-api.md)；二期开启只需置 `data_policy_enabled=true` 并录规则 | [05 §1.1](./05-scheduling-and-operations.md) 序 3；AC-14 判定见 [14](./14-acceptance-matrix.md) |

### 2.2 技术类 —— 已定论

| # | 议题 | **决定** |
| --- | --- | --- |
| **T1** | Codex 从未实机验证 | ✅ **M0 就做实机打通实验**：先写一个**最小透传代理**（无调度、无账本），把真实 Codex CLI 指向它、打到真实上游，**抓包确认它到底发什么/要什么**。用最小代价验证最大假设——早于任何调度逻辑 |
| **T2** | 字节透传 vs 首字前接管的缓冲张力 | ✅ **设上限，超限即提交并放弃本次接管**：缓冲达阈值（建议 256KB 或 5s，可配）仍未见可见内容 → 提交已缓冲字节、本跳不再可切换。**保证内存可控**；代价是极端长 reasoning 场景下不接管 |
| **T4** | 上游中转站不稳定（401/520 波动） | ✅ **主用 MOCK，真实上游只做关键验证**：日常开发与 CI 全走 mock；REAL 仅用于里程碑关键项（Responses 保真、Codex 打通、采集），允许重试窗口 |
| **R2** | 上游返回非 SSE 错误（如 Cloudflare 520 返 HTML） | ✅ **计为渠道故障并触发冷却**：非 2xx 或 Content-Type 非 SSE/JSON → attempt 记 `failed`、计入健康度、进冷却退避（与 5xx 同等处理） |

## 3. 一期范围的最终形态（S1~S4 确认后）

**做**：上游直连字节透传 · 内容感知 TTFT · 首字前接管（带缓冲上限）· 取消传播 · 按健康/余额/容量/价格/故障域调度 · **会话粘性** · 逐 Attempt 账本 · 价格与余额采集 · 单级 SLA · 管理 API 与二次确认 · 告警落库

**不做（二期）**：订阅制全套 · 主动测活 · 缓存切换损失预测 · 多 SLA 等级 · 外部告警通知

**产品目标兑现情况**：

| 目标 | 一期 |
| --- | --- |
| 前缀平均首字 ≤10 秒 | ✅ 承诺 |
| SLA 前提下降低实际成本 | ✅ 承诺（普通渠道） |
| 调度可解释可追溯 | ✅ 承诺 |
| 缓存命中率 ≥90% | ⚠️ **不承诺**（只做会话粘性，不做目标约束） |
| 订阅额度有效利用率 | ❌ **二期** |
