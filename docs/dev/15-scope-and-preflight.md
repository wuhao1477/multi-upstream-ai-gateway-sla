## 1. 一期 / 二期范围划分（已确认）

### 1.1 一期聚焦：SLA 自研网关

**目标**：把"最简单的智能调控 + SLA 保障"做扎实、做正确。

| 域 | 一期包含 |
| --- | --- |
| 上游对接 | 自研直连、Responses/CC 字节透传、SSE 旁路观察（[03](./03-upstream-layer.md)） |
| SLA 核心 | 内容感知 TTFT、动态期限、**首字前接管**、取消传播止损 |
| 智能调控（基础） | 按健康度/余额/容量/价格/故障域筛选与排序候选，生成 RoutePlan |
| 账本 | 逐 Attempt 账本（单一真相源）、价格版本、成本计算 |
| 采集 | **价格 + 余额 + Key 额度**采集（三家族适配器，[04](./04-collector-adapter.md)） |
| 平台底座 | 多实例、协议、数据边界、Key 存储、规模、管理 API |

### 1.2 二期推迟：订阅制适配

## 2. 开工前必须确认的隐患清单

> 负责人要求：**不接受"先做着看"**。以下每一项都需明确答复后方可开工。分四类。

### 2.1 范围类（需产品决策）

| # | 待确认 | 背景与影响 |
| --- | --- | --- |
| **S1** | **真实业务测活（FR-060~067）一期做不做？** | 它是"智能调控"里最复杂的一块：需探索预算、冷却、样本门槛、机会分配、补偿记账。**不做**则新渠道与恢复中渠道只能靠人工评估；**做**则 M2/M4 工作量显著上升。负责人说"最简单的智能调控"，倾向理解为**一期不做主动测活，只做被动健康度统计**——需确认 |
| **S2** | **缓存亲和调度（FR-054/055/056）一期做不做？** | 关系到"缓存率 ≥90%"这个产品目标。做 = 需维护缓存作用域与切换损失预测；不做 = 该目标一期不兑现 |
| **S3** | **SLA 等级体系一期做几级？** | 参数 1 定为"完全可配置"。一期若只做**单一等级**可大幅简化 selector 与容量保留；若做金/银/铜三级则需实现分级排队、容量预留、优先序 |
| **S4** | **数据许可硬过滤（FR-093）** | 已定为"个人/内部默认全允许"。确认一期**完全不实现**该过滤逻辑（仅保留字段），还是实现但默认放行 |

### 2.2 技术未验证类（有实测缺口）

| # | 待确认 | 风险 |
| --- | --- | --- |
| **T1** | **Codex CLI 从未真正对我们的网关发过请求** | 全部 Codex 行为（`session_id` 头、SSE 生命周期、`x-codex-turn-state`）来自**二手调研**（[13 §1](./13-research-reassessment.md)），未实机验证。**建议 M0 就做一次 Codex 直连打通实验**，早于任何调度逻辑 |
| **T2** | **字节透传与"首字前接管"存在设计张力** | 接管要求"首个可见内容前可切换"，即**必须缓冲上游字节直到判定出首字**。缓冲多大？上游发超长前导（如大量 reasoning）时是否会撑爆内存或拖慢 TTFT？**需在 M1 明确缓冲上限与超限策略** |
| **T3** | **100~1000 QPS 下的容量未验证** | 字节透传 + 每请求 goroutine + 旁路观察 + 账本写入，在 1000 QPS 下的内存/连接/PG 写入压力**无任何实测**。FR-114 与 FR-110（P99≤50ms）能否同时满足是未知数 |
| **T4** | **上游中转站稳定性差** | 实测中多次遇 401/520 波动（同一 key 几分钟内时通时断）。这会**同时影响开发联调与验收**。需确认：是否准备更稳定的上游？验收允许多大重试窗口？ |
| **T5** | **PG 单库承载账本 + 分区滚动未验证** | 月分区 + UUIDv7 + 1000 QPS 写入的实际表现未测 |
| **T6** | **~20 个渠道的价格数据来源未确认** | ISSUE-002 验证了 4 个站点；其余渠道是否都能采到价格？采不到时的人工录入流程谁来维护？ |

### 2.3 实现风险类（已知但无解法）

| # | 待确认 | 说明 |

## 3. 建议的确认顺序

1. **先定 §2.1 范围类（S1~S4）** —— 直接决定 M2/M4 的工作量与设计取舍。
2. **再定 §2.2 的 T1** —— 建议把"Codex 实机打通"提前到 M0，用最小代价验证最大假设。
3. **T2/T3/T5 属于"必须在 M1/M2 期间用实验回答"** —— 不需要现在有答案，但需要现在**承认它们是未知数**并安排验证点。
4. **R1~R3、O1~O3 可在对应里程碑前确认**，但不应拖过 M2。
