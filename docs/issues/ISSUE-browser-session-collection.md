# 增加账号密码登录与浏览器会话采集

## 目标

令牌无法完成后台采集时，允许使用用户预先配置的账号密码登录无头浏览器，复用登录会话完成采集。仅作用于余额、额度、Key、分组、价格和模型目录，不参与模型推理请求。

## 已确认的首站

- 站点：https://api.lyjxka.top/ ，登录页：`/sign-in`；NewAPI 系。
- 2026-10-08 公开页面检查：支持用户名／邮箱＋密码，前端登录调用 `POST /api/user/login`；网页接口携带 Cookie 和 `New-Api-User`。
- 尚未提交真实登录，未确认该站完全不支持访问令牌，也未完成登录后采集验收。不得把公开页面检查写成登录成功。

## 功能边界

1. 按站点账号启用浏览器访问；用户名、密码为启用前提，缺少时提示待配置，不影响原令牌路径。
2. 令牌访问优先；确认认证不可用、无法续期或某项采集必须使用登录会话时，才使用浏览器。网络超时、429、5xx、明确权限不足不触发重登。
3. 按账号隔离并复用会话，保存用户 ID；会话过期有限重登。密码错误停止自动尝试，待用户更新。
4. 密码与持久化会话加密保存，不进入日志、响应、截图或 Git；账号停用、清除凭据后停止使用相关会话。
5. 优先复用现有采集器、调度、限流和结果存储；浏览器只补认证／访问能力，不重新实现余额换算、分页和字段解析。

## 不做

不处理 CF／Turnstile、验证码代解、OAuth／Passkey／2FA 自动登录；不自动注册、改密、签到、生成或重置上游令牌；不做通用抓取平台、新队列、新管理系统或推理请求浏览器转发。首批完成 NewAPI 实际站点，其他家族有真实样本再扩展。

## 验收

- [ ] 已有令牌采集保持可用，未配置浏览器凭据不会启动浏览器。
- [ ] 首站配置账号密码后可真实登录，读取账号和 Key 数据；其余既有采集能力逐项记录结果，不支持的项目明确显示。
- [ ] 会话复用、过期重登、错误密码停止、按账号隔离和凭据清除行为可验证。
- [ ] 令牌仅部分接口不可用时，仅补该采集项；429／5xx 不触发登录；只读采集之外的操作不自动重放。
- [ ] 真 Chrome、真 PostgreSQL、真站点完成本地验收，管理页在 375px 可用；没有账号密码时明确记录未验收，不用假站点替代。

## 计划状态

规划与影响评估已完成，进入实施准备。开发顺序：凭据配置、首站登录与会话复用、接入既有采集、部署与真实验收；复用现有 Go 采集器，不新增独立 Node 服务或队列。

首站配置凭据后先验证普通 HTTP 登录是否足以完成采集；只有确认依赖浏览器环境时才接入 chromedp。生产端不引入 agent-browser。尚未完成真实账号登录验证，不能预先承诺完整采集可用。
